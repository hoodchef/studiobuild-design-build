# StudioBuild Business Card Template

Files:
- `business-card-front.svg`
- `business-card-back.svg`
- `business-card-front-print.svg` (guide-free artwork)
- `business-card-back-print.svg` (guide-free artwork)
- `business-card-back-print-qr.svg` (guide-free artwork with QR)
- `studiobuild-qr.svg` (QR source for QR card)
- `CMYK-EXPORT-CHECKLIST.md`

Specs:
- Trim size: 3.5in x 2in (1050 x 600 px at 300 DPI)
- Bleed: 0.125in on all sides (total canvas 1125 x 675 px)
- Safe area: 0.125in inside trim
- Color mode in file: RGB (convert to CMYK at print export if your printer requires it)

How to use:
1. Open the SVG files in Illustrator, Figma, Affinity Designer, or Inkscape.
2. Use `business-card-front.svg` + `business-card-back.svg` when you want guides visible.
3. Use `business-card-front-print.svg` + `business-card-back-print.svg` (or `business-card-back-print-qr.svg`) for final printer exports.
4. Export print PDF at 300 DPI with bleed enabled.
5. Follow `CMYK-EXPORT-CHECKLIST.md` before upload.

Recommended print stock:
- 16pt or 18pt uncoated matte (clean, architectural look)
- Optional soft-touch matte laminate
